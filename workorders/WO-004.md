Implementation notes

  One body: `draw(seed_env, purpose, *indices, shape, dist, **params) -> Array`. The construction is
  fixed by PLAN section 2.15 and the WO-004 notes of PLAN section 12.3, and every reproducibility
  property in the design depends on following it exactly:

      SeedSequence([seed_env, crc32(purpose), *indices])  ->  default_rng(seq)  ->  values

  with `crc32` being `zlib.crc32(purpose.encode())`. Use `zlib.crc32`, never Python's builtin
  `hash`: `hash` is salted per process, so a run would not reproduce across processes and CONTRACT
  rule 10's manifest would be worthless. Nothing else enters the key - no call counter, no wall
  clock, no length of a previous draw, no `shape`.

  Distribution table (parameter names are part of the contract; callers pass them by keyword):

      lognormal    mean_log, sigma      returns exp(N(mean_log, sigma**2)); float array
      normal       mean, sigma          float array
      bernoulli    p                    BOOLEAN array
      categorical  probs                INTEGER array of category indices

  Return exactly the requested `shape`, with the dtype the table states. `shape` vectorises over
  the trailing index: the environment calls, for example, `draw(seed_env, "yield", t, k,
  shape=(N,), dist="lognormal", mean_log=..., sigma=...)` for one shock per enterprise, so the whole
  `(N,)` vector comes from one key rather than from `N` keys.

  Properties the construction buys, all checked by T-U6:
    - determinism in `(seed_env, purpose, indices, shape, dist, params)` and INDEPENDENCE OF CALL
      ORDER, which is what makes the NumPy environment and the Phase-2 JAX port agree by
      construction (the WO-029 parity test) and what lets the period schedule of PLAN section 2.5
      be reordered without changing a trajectory;
    - common random numbers across arms whenever `seed_env` is shared (PLAN section 4.3), which is
      what makes the paired contrasts valid without variance-reduction tricks;
    - independence of distinct purposes at identical indices;
    - complete separation of `seed_policy`, which drives policy sampling and never appears in a key
      here.

  Errors, raised rather than papered over (all `ValueError`):
    - a `purpose` outside `PURPOSES`;
    - a `dist` outside `Dist`;
    - a missing distribution parameter, or an unknown one. Do not default `sigma` to 1, do not
      default `mean` to 0, do not accept `scale` as an alias for `sigma`. A caller that omits a
      parameter has a bug, and defaulting it would hide a silently wrong shock in a trajectory that
      still reproduces.

  Edge cases.
    - `numpy.random.SeedSequence` takes non-negative integer entropy. `crc32` is non-negative and
      `t`, `k`, `i` are non-negative by construction. If a caller ever needs a negative index, that
      is an interface question: file an AMBIGUITY REPORT. Do not take an absolute value, do not
      offset, do not hash the tuple.
    - `sigma = 0.0` is legitimate and common in Phase 1 (`audit_noise`, `channel_noise`,
      `self_obs_noise` are all 0.0). It must return exactly `mean` for `normal` and exactly
      `exp(mean_log)` for `lognormal`, with no warning, and it must still consume a key so that the
      key layout does not depend on the configuration.
    - `probs` for `categorical` arrives as a sequence; it must not be mutated, and it is the
      caller's business whether it sums to 1 - validate that it does and raise if it does not.
    - The yield shock of PLAN section 2.6 is `lognormal` with `mean_log = -sigma**2 / 2`, so
      `E[eps] = 1`. That algebra belongs to the CALLER (`gosplan/env/production.py`, WO-005), not
      here; `draw` takes `mean_log` as given. `tests/unit/test_production.py` checks the mean to
      1e-3 over 1e5 draws.

Forbidden

  - Module-level global generators, of any kind: no module-level `Generator`, no cached
    `SeedSequence`, no counter, no memo keyed on anything but the arguments of the call. A global
    reintroduces call-order dependence through the back door and destroys the parity and CRN
    properties above. If the cost of respawning a generator per key ever matters, the fix is a
    pure, key-addressed cache proposed through an AMBIGUITY REPORT, not a hidden stream.
  - `numpy.random.seed`, the legacy `RandomState`, or any use of the global numpy random state.
  - Python's builtin `hash()` on the purpose string.
  - Letting `seed_policy` enter a key, or deriving one seed from the other.
  - Importing jax, scipy, pandas or torch, at module scope or inside the function.
  - Adding a purpose to `PURPOSES`, or accepting a purpose not in it. The list is closed by PLAN
    section 2.15 plus `selfobs`; extending it is a spec change (CONTRACT rule 1) and needs a
    `spec/CHANGELOG.md` entry the lead writes.
  - Changing the signature, the keyword-only-ness of `shape` and `dist`, or the module docstring.
