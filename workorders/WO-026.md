## Must pass (verbatim test ids)

**None are frozen yet** — the revision writes them and names their ids here (CONTRACT rule 12).

Acceptance criteria PLAN §7.4 already fixes, and which the tests will encode:

- **strict-JSON responses with one retry and a documented fallback action (`π = 1`)**. The fallback
  is `gosplan.env.ministry.ministry_passthrough` — a transparent ministry — never an invented number
  and never a silently dropped episode;
- **pinned model versions**, written into the run manifest under `llm_models` (CONTRACT rule 10); a
  run whose model version is unpinned is not a result;
- **every prompt and completion logged**, verbatim, including the failed parse that triggered the
  retry and the one that triggered the fallback;
- the returned object is per-enterprise forwarded values **plus a free-text justification**
  (PLAN §2.14), in the order of `view.enterprise_ids`;
- the model receives a text rendering of the **same `MinistryView`** the rule-based ministry
  receives — no extra field, and in particular no true quantity (rules 5, 6);
- the **manipulation check**: after each episode, in a **fresh context**, the model is asked to name
  the closest real-world analogue of the game it played; the answer is logged so results can be
  stratified by whether it named Soviet planning. The check runs after the episode, in a context
  that cannot leak back into ministry decisions.

Green after this change: the full frozen Phase-1 suite. The adapter must import with no network
client present and no model key configured, so CI never calls a model.

## Implementation notes

Provisional until the lead revises the spec and supplies the prompts.

Study design this adapter must be able to serve (PLAN §7.4, and the constants already in
`gosplan/agents/llm_ministry.py` and `gosplan/experiments/llm_study.py`):

```
  2 framings        neutral vocabulary / historical vocabulary
× 3 payoff arms     baseline
                    padding-dominated       a = 1, pen large, so forwarding padded numbers is
                                            strictly worse for the ministry
                    overfulfilment-optimal  λ = 0, s large, so smoothing away overfulfilment is
                                            strictly worse
× ≥ 2 models
× 20 episodes per cell
```

The discriminating measure is whether ministry behaviour **tracks the payoff arm** (reasoning) or
stays at the historical pattern regardless (retrieval); the framing contrast is secondary. This card
supplies the machinery; WO-035 runs the design and computes the measure.

What PLAN does **not** decide, and what the revision must state before this card is issued:

- the exact text rendering of a `MinistryView` — which fields, in what order, with what units, and
  whether numbers are rounded (rounding is itself a manipulation-strength choice);
- the JSON schema of a valid response, and what counts as a parse failure short of invalid JSON
  (missing enterprise, wrong length, negative value, non-finite value);
- whether the free-text justification is passed back into the next period's prompt;
- the transcript file format and directory layout under `runs/llm_study/transcripts/`;
- which client library and which pinned model ids — PLAN §15 item 8 leaves current model
  availability and pricing to WO-000, and the tier mapping is recorded in the manifest.

## Forbidden

- Writing the framing prompts or the manipulation-check prompt. PLAN §12.5 assigns both to the
  LEAD; a prompt invented here would silently become the experiment.
- Letting the model see anything the rule-based ministry cannot: no `State`, no true `S`, `y` or
  `X`, no welfare, no other ministry's view (rules 5, 6).
- Any retry policy other than the one PLAN §7.4 fixes (exactly one retry, then the documented
  fallback `π = 1`); any silent re-prompt, any "repair the JSON" pass, any dropped episode.
- Suppressing a logged prompt or completion, including the failures.
- Running the study from this card: no model calls in CI, no episodes, no tables. That is WO-035.
- Computing PLAN §4.1 rows **2, 5, 6, 7** — held out until WO-030.
