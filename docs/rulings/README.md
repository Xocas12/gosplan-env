# Lead rulings

The design rulings made while the environment, the learners and the studies were built:
AMBIGUITY-003 to AMBIGUITY-023. Each one settles a point the plan or the frozen spec left open,
states what was decided and why, and is cited by id from `spec/CHANGELOG.md`, the code and the gate
records under `runs/`.

They were first filed under `workorders/`. That directory was removed with the work-order apparatus,
and the rulings moved here unchanged. Older records that cite `workorders/AMBIGUITY-0NN.md` mean
`docs/rulings/AMBIGUITY-0NN.md`.
